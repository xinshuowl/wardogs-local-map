# 材质发黑的全量复查与第二次修复

## 结论与范围

上次金属度和 IBL 修复没有触及源贴图本身的黑底以及负缩放实例的正反面问题。本次确认这两项，并在真实 GLB 上重现黑门框、黑饰条、黑钢梁和镜像内表面外露；修复后进行三图全部材质 GPU 渲染与完整网站模式检查。

全部 318 个 GLB 解码检查：没有缺少 normal / UV 的部件，没有非有限值或长度低于 0.01 的顶点法线，没有 GLB 节点级负行列式。负缩放来自实例文件，合计 7,486 个；仅检查原始 GLB 会漏掉它。位置文件亦包含零缩放的销毁状态对象，不能把它们当成应该提亮的模型。

三图 207 / 204 / 194 张底色纹理与 136 / 140 / 134 张法线纹理均解码读取。64×64 缩略统计未发现平均蓝通道低于 160 的法线图；这只是排除普遍缺蓝通道，不等于每个法线像素都已经还原游戏效果。Three.js 颜色纹理 sRGB、法线 NoColorSpace 和 UE 法线 Y 翻转保持正确；参考站本地源码也采用相同法线翻转、sRGB 实例颜色解码，未将 cpd 字段误判为必须禁止其它实例染色的依据。

详细几何与实例扫描记录：`model-surfaces-audit.json`。纹理统计：`bakurani-texture-audit.json`、`ozeti-texture-audit.json`、`zestafona-texture-audit.json`。

## 修复一：源纹理黑底

直接比较下载缓存与本地压缩纹理，确认以下异常在源 WebP 中已经存在，不是本地丢失文件或法线加载失败：

- `b7cceb6cf4fe7597.webp`：全部 RGB 为零；使用 `MI_Floor2TrimSheetTinted02` 的源 color，并保留原 normal。
- `833873520a0b6149.webp`：钢板源底色均值约 0.66 / 255，几乎全黑。
- `ec54d508479b3b1a.webp`：室内木饰条，约 97% 缩略像素接近黑色。
- `f6cefd2b258cf789.webp`：涂漆木饰条，约 97% 缩略像素接近黑色。
- `0b28d5b1c7645328.webp`：工业钢梁图集，约 84% 缩略像素接近黑色。

后四张生成独立修复图：20–64 的 sRGB 最大通道区间平滑过渡补底色，64 以上的原像素保持；保留 UV 排布、原法线、亮色条带和图集细节。取消这四类修复图原先的全局 colorGain，避免恢复后的底色再次倍增曝光。源文件、哈希和位置数据未变。

按源资源引用统计，这些材质涉及三图 305 / 271 / 297 个模型资产和 59,864 / 37,360 / 42,869 个实例。该数包含未显示及销毁状态实例，不是当前画面绘制数量。

修复属于缺失底色的近似补全，未声称找回原游戏完整材质。黑塑料、轮胎、BlackUnlit、烧毁车辆、武器及徽标图集的黑色背景没有被统一提亮。电缆桥架的纹理缩略图有大量黑色，但真实 UV 映射后的金属表面正常，因此保留。

## 修复二：镜像实例

Three.js 的 InstancedMesh / BatchedMesh 共用绘制正反面状态，不能像独立 Mesh 那样按每个负行列式实例切换正面绕序。直接提交镜像矩阵会剔除外侧、露出内侧，影响照明、法线贴图和阴影。

现在在模型批次准备阶段按行列式符号分组。镜像组反射一次 X 轴几何、反转三角形索引，同时抵消实例的 X 负号，保留原世界位置与外向法线。普通模型的其余两个负轴组合也保持正行列式。处理同时用于普通实例、multi-draw 及透明批处理回退，碰撞和拾取使用同一变换。

镜像几何按模型与 LOD 缓存，只在首次使用时构建；分组和构建分帧执行，已显示模型继续常驻。中断构建可继续补齐，切图释放暂存与完整几何，避免半成品或重复分配。

- 浏览器 `scripts/model-surface-audit.html` PASS：656 + 649 + 649 = 1,954 条材质全部实际渲染，23 个修复条目的前后中心亮度均改善。没有 GPU shader、资源加载、console warning/error。

- 独立 43823 端口检查完整网站：Bakurani 普通 3D 模型近景；三图炮兵、Orbit → Fly → Walk 和地图切换；模型、八层地表、天空与阴影显示，无控制台错误。属于入口与场景冒烟测试，没有将瞬时 FPS 当作性能提升结论。正式 4173 的个人标记、武器和预设未修改。

## 不夸大的边界

已覆盖全部资源/材质条目和代表性实际模型，不等于人工逐一走过 364 万个实例或每个观察角度。源数据缺完整材质图层、GI、AO 和部分动态效果；徽标图集黑背景、实际阴影及原本黑色物体仍然可能偏暗。剩余具体异常可用本次对照页和模型名继续定位，不能把所有黑色都当作故障或宣称完全等同原游戏。
