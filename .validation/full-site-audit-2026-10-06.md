# 全站检查与优化验收 · 2026-10-06

本轮继续检查单页地图应用的页面入口、按钮、地图工具、三维资源和响应式布局。浏览器使用独立服务 `http://127.0.0.1:43828`，不接触正式服务端口；验收产生的房间记录已清理。

## 本轮发现并修复

- `app.js`：二维地图指针事件区分标记单击、地图拖动、Shift 放置、炮兵选点和多指缩放；普通拖动会更新地图平移，标记单击仍打开详情。
- `artillery.js`：二维炮兵射程圆移出可拖动分组。射程圆只显示，只有炮位和目标的 20 px 标记可以拖动。
- `artillery.css`：性能诊断导航层提升到 `z-index: 24`，位于默认瞄具层之上；折叠时明确隐藏内部 `display:flex` 的性能控件。
- `enhancements.css`：三维「画质与性能」折叠时明确隐藏所有详情内容，避免按钮仍占位或遮挡底部地图控件。
- `workspace.css`、`artillery-sight.js`：地图容器禁止隐式滚动；全尺寸瞄具临时移到 `body`，关闭后恢复原容器；三维工具面板与绘图入口不再互相覆盖。

## 地图资源与自动验证

- 2D 拖动复核：从 3D 切换到 2D 后，空白区域拖动 `(120, 60)` px，底图平移同量；从 Tower 1 标记拖动 `(-80, -45)` px，底图同步移动且未误开详情；炮兵模式拖动 `(70, 35)` px，底图同步移动且炮位、目标坐标不变。两条射程圆的计算样式均为 `pointer-events:none`；复核后控制台无 warning / error。

- `npm run verify`：资源哈希、三图位置与 GLB / LOD、高度、地形加载恢复、导航、模型加载、31 项 UI 状态、光照阴影和三图材质表面检查通过。
- `npm run verify:updates`：5 项版本、缓存、路径保护和回滚检查通过。
- `npm run verify:artillery`：24 组加农炮、17 行迫击炮表、坐标、高度、弧线、Fly / Walk 与瞄具状态检查通过。
- 本轮浏览器在模型完成后未捕获 console warning / error；自动检查覆盖全部 3 张地图的资源集合、光照与材质分类。浏览器现场检查是本机单一 GPU，会话持续时间有限，不能替代所有硬件的长期耐久测试。

## 仍然成立的边界

- 已显示的模型保留在场景资源与实例缓存中，远处使用低细节模型；探索范围增加会增加内存和显存，刷新或切图才会释放本图资源。
- 整图预载表示资源缓存完成，不保证同一帧已经绘制全图最高细节。
- 本地页面没有 MetaForge 云账号、实时玩家位置、占领状态或 Steam 服务；炮兵轨迹用于游戏内计算参考，不是实弹校准。
