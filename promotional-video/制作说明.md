- `wardogs-promo-1080p.mp4`：60 秒，1920×1080，30 fps，H.264 / AAC，中文字幕已烧录，配原创电子音乐，无配音。
- `cover.jpg`：1920×1080 的 B 站横版封面。

- `B站发布文案.md`：标题、简介、标签、置顶评论。
- `original-music.wav`：本片程序合成的原创配乐，48 kHz 双声道。

# 可重复制作

1. 使用带有 NumPy、Pillow、ReportLab 的 Python 运行 `source/build_assets.py`，生成配乐、二维码、字幕。
2. 从项目目录运行 `node promotional-video/source/render-server.mjs`，打开 `http://127.0.0.1:4181/`。
3. 使用制作台预览各镜头；点击「导出60秒成片」生成 `video-only.mp4`，需要本机 FFmpeg。
4. 运行 `python promotional-video/source/finalize.py`，使用 FFmpeg 双遍音量归一化合成 AAC 音频与 faststart MP4，并生成封面和抽帧检查图；此步骤需要 Pillow。

制作台仅监听本机 4181 端口，独立于地图网站；完成后关闭即可。源代码与素材均留在本目录，便于后续修改文案与重新制作。
